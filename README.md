# NEXTSTEP SUPPORT — دليل التسليم

موقع استقبال وتقييم المشاريع التابع لـ NextStep AI. موقع ثابت (HTML/CSS/JS) + Supabase، جاهز للنشر على GitHub Pages.

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `how.html` | كيف نعمل؟ + معايير التقييم |
| `faq.html` | الأسئلة الشائعة |
| `apply.html` | نموذج التقديم (6 مراحل، حفظ تلقائي) |
| `success.html` | نجاح الإرسال + الرقم المرجعي |
| `privacy.html` | الخصوصية والتنبيه |
| `admin.html` | لوحة الإدارة (محمية بتسجيل الدخول، غير مفهرسة) |
| `404.html` | صفحة الخطأ (يستخدمها GitHub Pages تلقائيًا) |

## الملفات المشتركة
`css/style.css` · `js/config.js` (**الملف الوحيد الذي تعدّله لربط Supabase**) · `js/common.js` · `js/apply.js` · `js/success.js` · `js/admin.js` · `assets/` (الشعار وصورة المؤسس) · `robots.txt` · `schema.sql`

## النشر (حوالي 15 دقيقة)
1. في Supabase: شغّل `schema.sql` في SQL Editor.
2. أنشئ حساب المسؤول من Authentication > Users، ثم شغّل السطر الأخير في `schema.sql` ببريده.
3. افتح `js/config.js` وضع `url` و`key` (المفتاح العام anon فقط).
4. ارفع **محتوى المجلد كاملًا** إلى مستودع GitHub، ثم Settings > Pages > الفرع main والمجلد root.
5. من Supabase > Authentication > URL Configuration أضف رابط الموقع النهائي.

## الأمان
- الزائر يرسل طلبًا فقط، ولا يقرأ ولا يعدّل (سياسات RLS)، والمسؤول يُحدَّد في `admin_users`.
- الملفات في حاوية خاصة (5MB، صور وPDF)، وروابطها مؤقتة.
- تحقق من الحقول في المتصفح والخادم، وحد 5 طلبات/ساعة لكل بريد، ومنع التكرار، وحقل مخفي ضد الروبوتات.

## قائمة اختبار قبل الإعلان
- [ ] تقديم طلب كامل من الهاتف مع صورة وPDF، وظهور الرقم المرجعي.
- [ ] تقديم نفس الطلب مرتين (يجب أن يُرفض الثاني).
- [ ] التأكد أن حسابًا غير مسؤول لا يقرأ الطلبات.
- [ ] مراجعة طلب: تقييم، حالة، ملاحظة، رفض بسبب، ثم السجل والتصدير.
- [ ] فتح ملف مرفق من الإدارة، وتجربة Chrome وSafari وأندرويد وآيفون.
- [ ] اعتماد نص الخصوصية من الإدارة.
